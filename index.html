About & credits

Line Art Playground runs open-source image-to-line-art algorithms side by side, so you can compare them and export plotter-ready SVG files. All processing happens on your device: JavaScript algorithms run directly, and Python algorithms run in Pyodide, which the browser downloads from the jsDelivr CDN on first use. Your images are never sent anywhere.

The algorithms are the work of their original authors, credited above, and are used under their licenses. This project is independent: the original authors are not affiliated with it and do not endorse it. See third-party notices for details and the changes made to each algorithm.
